# 星穹铁道抽卡记录分析

把《崩坏：星穹铁道》导出的抽卡 JSON 记录整理成 CSV，并统计角色活动跃迁中五星角色的出货间隔。

这是一个个人练手项目，用真实数据完整走一遍 **原始数据 → 清洗 → 筛选 → 统计分析 → 结果输出** 的流程。

## 功能

1. **记录整理**：把嵌套的 JSON 抽卡记录摊平成一行一抽的 CSV；
2. **卡池筛选**：只保留角色活动跃迁（卡池编号 `11`）；
3. **间隔分析**：找出每个五星出现在第几抽，计算相邻两个五星之间隔了多少抽，并输出平均、最小、最大间隔。

## 数据说明

原始数据来自游戏内的「跃迁记录」导出功能，格式为 JSON，结构是「卡池编号 → 该卡池的抽卡列表」。

| 卡池编号 | 含义 |
| --- | --- |
| `1` | 常驻跃迁 |
| `2` | 新手跃迁 |
| `11` | 角色活动跃迁 |
| `12` | 光锥活动跃迁 |

原始 JSON 里还有一个 `uid` 字段，表示账号 ID，它不是抽卡记录，脚本中已跳过。

整理后 CSV 的字段：

| 字段 | 说明 |
| --- | --- |
| 抽卡时间 | 抽卡时间，格式 `YYYY-MM-DD HH:MM:SS` |
| 卡池名称 | 卡池的中文名称 |
| 星数 | 3 / 4 / 5 |
| 名称 | 抽到的角色或光锥名称 |

## 运行方式

环境：Python 3.8 及以上，只使用标准库 `json` 和 `csv`，**不需要安装任何第三方包**。

在项目根目录下依次运行：

```bash
python 记录整理.py
python 限定池子记录分析.py
python 五星间隔分析.py
```

脚本里的路径是相对路径（`data/...`），所以请在项目根目录运行。

> 第一步需要自己的原始导出文件，重命名为 `data/跃迁记录.txt`。这个文件包含账号信息，**没有上传到仓库**。
> 仓库中已包含整理好的 CSV，因此即使没有原始文件，也可以直接从第二步开始运行。

## 分析结果

当前样本：角色活动跃迁 **1090 抽**（2025-11-05 至 2026-09-28），共 **17 个五星**，其中 **16 个**可以计算间隔。

| 星级 | 数量 |
| --- | --- |
| 5 星 | 17 |
| 4 星 | 145 |
| 3 星 | 928 |

| 指标 | 数值 |
| --- | --- |
| 平均间隔 | 65.31 抽 |
| 最小间隔 | 8 抽 |
| 最大间隔 | 90 抽 |

16 个间隔的完整列表：

```
73, 88, 89, 70, 19, 8, 59, 83, 11, 65, 90, 80, 81, 81, 77, 71
```

## 结论与局限

- 样本只有 16 个间隔，数量太少，**不能用来推断官方概率**，它只是对个人抽卡记录的描述统计；
- 记录开头的第一个五星之前，可能存在未被导出的抽卡，因此第一个五星的间隔记为 `null`，不参与平均；
- 这里的「第几抽」是导出记录内的序号，不等于游戏内的保底计数；
- 导出记录可能存在时间跨度限制，历史数据不一定完整。
